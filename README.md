# Hanzla Sajid — Portfolio

A static, two-mode portfolio for Hanzla Sajid:

- `/` presents SDET and QA engineering work.
- `/product/` presents Product Management work.

The site uses plain HTML, CSS and JavaScript and is ready for GitHub Pages.

## Contact form

The contact form posts to `https://formspree.io/f/xdeegvkn`. Email and LinkedIn remain available as fallbacks.

## Local preview

Run a static server from this directory, for example:

```sh
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
