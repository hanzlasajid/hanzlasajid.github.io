# Hanzla Sajid — Portfolio

A static, two-mode portfolio for Hanzla Sajid:

- `index.html` presents SDET and QA engineering work.
- `product.html` presents Product Management work.

The site uses plain HTML, CSS and JavaScript and is ready for GitHub Pages.

## Contact form

Replace `https://formspree.io/f/REPLACE_ME` in both HTML files and `content.json` with the real Formspree endpoint. Until then, the form explains that it is not connected and directs visitors to `hanzla.sajid@gmx.de`.

## Local preview

Run a static server from this directory, for example:

```sh
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
